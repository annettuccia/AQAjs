# AQAjs

## Каждая тема реализована в *отдельной ветке*

Например, если тема называется в Google Docs *Темы: переменные, операторы*, то она будет находится в векте *1_Variables*, где 1 - номер по очереди темы, Variables - название первого слова темы на английском.

При необходимости предоставлять ответы на задание в Google Docs, ссылка на него будет находится в файле README.md в соответствующей ветке задания с остальными файлами (при их наличии).
